# Curriculum Question Bank

## Scope

Create separate Word documents and editable Markdown source for these 13 class groups:

- **Nigeria:** JSS 1, JSS 2, JSS 3, SS 1, SS 2, SS 3
- **England (working interpretation of British):** Grade 6–12, mapped approximately to England Years 7–13. Grades 11–12 require distinct subject pathways because post-16 study is subject-selected rather than a single common curriculum.

Each class document is to contain distinct, level-appropriate sections for Science, Arts/Humanities, and Commercial subjects offered at that level. Each included subject requires at least 100 objective questions, followed by an answer guide with explanations. Keep each country's curriculum and each class level separate; do not reuse questions between class groups.

## Document standard

- One Word document per class group; keep a matching editable Markdown source.
- Label each question with its class and subject; use four answer options and one unambiguous correct answer.
- Put answers and concise teaching explanations in a separate answer-guide section after the questions.
- Use locally appropriate examples, units, spelling, and terminology; identify the curriculum/level on the title page.
- Keep subject selection explicit in a class-by-class curriculum map before drafting questions, especially for senior-secondary and post-16 pathways.

## Production order

Build and review one class document at a time, beginning with Nigeria JSS 1, then continuing through the Nigerian levels and the England grade/year groups. Generate the Word files only from reviewed source content so that the answer keys stay synchronized.

## Assumptions to confirm during curriculum mapping

- Nigeria follows the applicable Nigerian national/basic and senior-secondary curriculum, with senior subjects grouped by science, arts/humanities, and commercial pathways.
- “British Grade 6–12” is provisionally interpreted as England’s curriculum with approximate Year 7–13 equivalents. Scotland, Wales, and Northern Ireland have different structures; adjust this mapping if another UK nation is intended.
- Include separate CRS and Islamic Studies sections for Nigerian levels where appropriate, and use Yoruba for the Nigerian-language subject.
- The current web quiz in `script.js` is separate from these curriculum documents unless integration is requested.

## First class batch

The first curriculum map is Nigeria JSS 1: [nigeria-jss1-curriculum-map.md](nigeria-jss1-curriculum-map.md). Validate subject offerings before drafting the 100-question sections, as language, religion, and practical/vocational offerings can vary by school and state.
